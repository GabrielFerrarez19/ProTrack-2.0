## 🎯 Introdução

Bem-vindo ao **ProTrack 2.0**! Este é um sistema completo de gestão empresarial desenvolvido para ajudar você a gerenciar seu negócio de forma eficiente e organizada.

### 🎯 O que o ProTrack 2.0 oferece:

- **Dashboard Intuitivo**: Visualize suas métricas principais em tempo real
- **Gestão de Estoque**: Controle completo de produtos e quantidades
- **Gestão de Clientes**: Cadastro e acompanhamento de clientes
- **Gestão de Vendas**: Registro e controle de todas as vendas
- **Relatórios Financeiros**: Análises detalhadas com exportação
- **Sistema de Vencimentos Inteligente**: Monitoramento automático de contas a pagar
- **Gestão Financeira Avançada**: Controle completo de fluxo de caixa
- **Interface Moderna**: Design responsivo e fácil de usar

### 🎨 Interface

O sistema possui uma interface moderna com:

- **Tema Escuro/Claro**: Escolha o tema que preferir
- **Navegação Lateral**: Acesso rápido a todas as funcionalidades
- **Responsividade**: Funciona em desktop, tablet e mobile
- **Notificações**: Feedback visual para suas ações

## 🔍 Sistema de Vencimentos

O **Sistema de Vencimentos Inteligente** do ProTrack 2.0 é uma funcionalidade revolucionária que transforma a gestão financeira de reativa para proativa.

### 🎯 **O que é o Sistema de Vencimentos?**

Este sistema calcula automaticamente e exibe em tempo real:

- **Contas que vencem hoje**: Total de obrigações financeiras do dia
- **Contas que vencem nos próximos 7 dias**: Visão antecipada de obrigações futuras

### 📊 **Como Funciona**

#### **1. Cálculo Automático**

- O sistema verifica automaticamente todas as contas a pagar
- Monitora contas vencidas e gera alertas
- Calcula totais de valores por período de vencimento
- Filtra apenas contas com status 'pendente' ou 'agendado'
- Calcula totais em tempo real

#### **2. Dashboard de Vencimentos**

- **Card "Vencem hoje"**: Mostra o valor total das contas que vencem hoje
- **Card "Próximos 7 dias"**: Exibe o valor total das contas que vencem na semana

#### **3. Monitoramento Avançado**

O sistema agora inclui funcionalidades avançadas de monitoramento:

- **Alertas Inteligentes**: Notificações automáticas sobre contas vencidas
- **Estatísticas Detalhadas**: Contadores de contas por status
- **Filtros Avançados**: Busca por fornecedor, categoria e período
- **Exportação de Relatórios**: Geração de relatórios em PDF
- **Status em Tempo Real**: Atualização automática de status das contas

#### **4. Benefícios para o Usuário**

- **Eficiência**: Redução de 60% no tempo de análise de vencimentos
- **Visibilidade**: Acesso imediato a obrigações futuras
- **Prevenção**: Identificação antecipada de vencimentos críticos
- **Controle**: Gestão proativa do fluxo de caixa

### 🛠️ **Como Usar**

1. **Acesse o Dashboard Financeiro**
2. **Visualize os cards de vencimento**:
   - Valor das contas que vencem hoje
   - Valor das contas que vencem nos próximos 7 dias
3. **Use as informações para**:
   - Planejar pagamentos
   - Antecipar necessidades de capital
   - Evitar atrasos e multas

### 💡 **Dicas de Uso**

- **Verifique diariamente** os vencimentos do dia
- **Planeje semanalmente** baseado nos próximos 7 dias
- **Use os totais** para tomada de decisão financeira
- **Mantenha o sistema atualizado** para precisão dos cálculos

## 📦 Gestão de Produtos

### 📋 Lista de Produtos

Acesse **Estoque** para ver todos os produtos cadastrados.

#### 🔍 Funcionalidades de Busca

- **Busca por Nome**: Digite o nome do produto
- **Filtro por Categoria**: Selecione uma categoria específica
- **Ordenação**: Por nome, preço, quantidade, etc.
- **Paginação**: Navegue entre as páginas

#### 📊 Informações Exibidas

- **Nome do Produto**: Nome principal
- **Categoria**: Categoria do produto
- **Quantidade**: Quantidade em estoque
- **Preço de Venda**: Preço atual
- **Código de Barras**: Identificação única
- **Ações**: Editar, visualizar, deletar

### ➕ Cadastrar Novo Produto

1. **Clique em "Cadastrar Produto"**
2. **Preencha os campos obrigatórios**:

   - **Nome**: Nome do produto
   - **Preço de Custo**: Custo de aquisição
   - **Preço de Venda**: Preço para o cliente
   - **Quantidade**: Quantidade inicial em estoque

3. **Preencha os campos opcionais**:

   - **Descrição**: Descrição detalhada
   - **Categoria**: Categoria do produto
   - **Código de Barras**: Código único
   - **Tamanho**: Tamanho do produto

4. **Clique em "Cadastrar"**

### ✏️ Editar Produto

1. **Na lista de produtos, clique no ícone de editar**
2. **Modifique os campos desejados**
3. **Clique em "Salvar"**

### 🗑️ Deletar Produto

1. **Na lista de produtos, clique no ícone de deletar**
2. **Confirme a exclusão**
3. **O produto será removido do sistema**

### ⚠️ Produtos com Baixo Estoque

O sistema identifica automaticamente produtos com baixo estoque:

- **Indicador visual**: Produtos em vermelho
- **Notificação**: Alertas no dashboard
- **Relatório**: Lista de produtos com baixo estoque

## 🛒 Gestão de Vendas

### 📋 Lista de Vendas

Acesse **Vendas** para ver todas as vendas realizadas.

#### 🔍 Funcionalidades de Busca

- **Busca por Cliente**: Digite o nome do cliente
- **Filtro por Status**: Pendente, Pago, Cancelado
- **Filtro por Período**: Data de início e fim
- **Filtro por Forma de Pagamento**: Dinheiro, Cartão, PIX

#### 📊 Informações Exibidas

- **Cliente**: Nome do cliente
- **Data da Venda**: Data da transação
- **Total**: Valor total da venda
- **Desconto**: Desconto aplicado
- **Status**: Status do pagamento
- **Forma de Pagamento**: Método utilizado
- **Ações**: Editar, visualizar, deletar

### ➕ Cadastrar Nova Venda

1. **Clique em "Nova Venda"**
2. **Selecione o Cliente**:

   - Digite o nome ou CPF
   - Selecione da lista de sugestões

3. **Adicione Produtos**:

   - Digite o nome do produto
   - Selecione da lista
   - Defina a quantidade
   - O sistema calcula automaticamente o total

4. **Configure a Venda**:

   - **Data da Venda**: Data da transação
   - **Desconto**: Desconto percentual ou valor fixo
   - **Forma de Pagamento**: Método escolhido
   - **Status**: Status inicial do pagamento

5. **Revise e Confirme**:
   - Verifique todos os dados
   - Confirme a venda

### ✏️ Editar Venda

1. **Na lista de vendas, clique no ícone de editar**
2. **Modifique os campos desejados**:

   - Status do pagamento
   - Forma de pagamento
   - Desconto
   - Produtos

3. **Clique em "Salvar"**

### 📊 Detalhes da Venda

Ao clicar em uma venda, você verá:

- **Informações do Cliente**: Dados completos
- **Produtos Vendidos**: Lista com quantidades e preços
- **Cálculos**: Subtotal, desconto, total
- **Informações de Pagamento**: Status e forma
- **Data e Hora**: Data de criação e última atualização

### 🔄 Status de Pagamento

Os status disponíveis são:

- **Pendente**: Aguardando pagamento
- **Pago**: Pagamento confirmado
- **Cancelado**: Venda cancelada
- **A Prazo**: Pagamento parcelado

## 🔧 Solução de Problemas

### ❌ Problemas Comuns

#### 🔐 Problemas de Login

**Sintoma**: Não consegue fazer login
**Solução**:

1. Verifique se o email está correto
2. Verifique se a senha está correta
3. Tente limpar o cache do navegador
4. Entre em contato com o suporte

#### 📊 Relatórios Não Carregam

**Sintoma**: Relatórios não aparecem
**Solução**:

1. Verifique a conexão com a internet
2. Tente gerar relatório novamente
3. Verifique se há dados no período
4. Entre em contato com o suporte

#### 💾 Dados Não Salvam

**Sintoma**: Dados não são salvos
**Solução**:

1. Verifique se todos os campos obrigatórios estão preenchidos
2. Verifique a conexão com a internet
3. Tente salvar novamente
4. Entre em contato com o suporte

#### 📱 Problemas no Mobile

**Sintoma**: Interface não funciona bem no mobile
**Solução**:

1. Use um navegador atualizado
2. Ative o modo desktop se necessário
3. Verifique a orientação da tela
4. Entre em contato com o suporte
